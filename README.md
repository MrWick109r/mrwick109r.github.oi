Technologies used

HTML5 — semantic page structure (header, nav, main, section, article, footer)
CSS3 — custom design system (CSS variables), responsive grid/flexbox layout, no framework
JavaScript (vanilla) — no libraries or frameworks
Fonts: Bricolage Grotesque and Figtree (Google Fonts)

Features

Responsive layout for desktop, tablet, and mobile
Mobile navigation menu with animated hamburger toggle
Scroll animations that replay every time a section scrolls into view (staggered fade, slide, wipe, and line-draw effects)
Reading-progress bar and nav that highlights the current section
Dynamic colour themes: pick a swatch in the theme carousel and the whole site adopts its colours (contrast-checked, and remembered between visits)
Project carousel with arrow buttons, keyboard arrows, and touch swipe
Sticky header with smooth-scroll navigation
Skills grid covering databases, web development, systems development, and systems analysis
Respects prefers-reduced-motion for accessibility

Projects featured on the site

Java Banking System — a functioning banking system built in Java (balance checks, deposits, withdrawals, transfers)
Banking System — the earlier C++ version of the same concept
Data Validation System — a desktop form-validation system that checks user input against presence, type, length, format and range rules
